What it is overview

MathTech is a web-based digital workbook for Mathematics. Students read comic-style lessons, answer graded quizzes, and write a reflection for each topic. Teachers decide when each topic opens, and monitor every student's progress, scores and reflections.

Student

  • Reads comic-style lessons
  • Answers practice and graded activities
  • Writes and edits a reflection per topic
  • Sees scores, correct answers and explanations

Teacher

  • Opens or schedules each topic
  • Monitors class averages and per-student scores
  • Reads each student's reflection per topic
  • Seeded account only — registration always makes a student

Key features how it works

Topics locked by default

A new topic, a fresh deployment or a server restart never exposes content. Every topic stays closed until the teacher opens it or picks a date. The choice is saved and survives restarts, and can be edited any time.

Stable topic order

Topics always appear in curriculum order — Week 1 Topic 1 first — using stored week and topic numbers, never the release date, which would reshuffle the list whenever a schedule changed.

Server-side grading

The correct answer is never sent to the browser, so it cannot be read from the developer tools. The server re-checks every answer on submit.

Math-aware answers

₱1,234.50, 1,234.50 and 1234.5 all count as the same answer, with a small tolerance for centavo rounding.

Comic-style lessons

Lessons are authored as numbered panels with character dialogue and rendered as real comic panels with speech bubbles and portraits. New content becomes comic-style automatically.

Reflection per topic

Students write a reflection in their own words and can edit it any time. They are told plainly that the teacher can read it. No student can read or edit another student's writing.

Content 4 topics

WeekTopicSubjectItems

Each topic ships with a 6-panel comic discussion, about 9 key concepts, 4 worked examples, 4 practice items and 10 graded items. Every answer key was verified by submitting it through the live grading engine and confirming 100%.

On first start the backend creates the teacher account and all four topics. All topics begin locked — open them from the teacher's Schedule page.

Known gaps honest list

  • Real-time monitoring uses 30-second polling, not websockets — fine for a classroom, but it will not scale to many simultaneous teachers.
  • Lesson HTML is trusted rather than sanitised, though only teachers can write it.
  • No automated tests, though jest and supertest are installed.
